# 投放要求与常见句式扩展（2026-09-22）

## 使用

在“文本知识抽取”页使用“增强抽取（推荐）”或“词典规则基线”，两者均使用新版 `clause_guard_v2` 句式层。纯神经模型继续单独用于实验对照，本次未重训或替换模型。服务地址：http://127.0.0.1:8765/ 。

输入“香蕉皮属于湿垃圾,应该扔进垃圾桶里”，现在返回：

- 香蕉皮 → 属于 → 湿垃圾
- 香蕉皮 → 投放要求 → 扔进垃圾桶里

“扔进垃圾桶里”整体标为 METHOD，投放目的地“垃圾桶”不再作为独立 ITEM 展示。

## 已扩展的句式

| 类型 | 例子 |
| --- | --- |
| 投放动词与目的地 | 应该丢进／扔入／放到／投入垃圾桶里，送往回收站，交给回收人员 |
| 命令与义务表达 | 请把香蕉皮丢进垃圾桶里；香蕉皮必须沥干水分；投放要求是…… |
| 省略主语 | 香蕉皮属于湿垃圾，应该丢进垃圾桶里 |
| 连续投放步骤 | 香蕉皮先沥干水分，再装袋，最后丢进垃圾桶里 |
| 防护与包装 | 玻璃瓶应该轻拿轻放／用报纸包裹好再投放／连同包装一起投放 |
| 并列物品 | 香蕉皮和苹果核应沥干水分，再丢进垃圾桶里 |
| 分类改写 | 归类为、划分为、算作、视为、的分类是，以及“香蕉皮：湿垃圾” |
| 类别列举 | 湿垃圾主要有香蕉皮和苹果核；属于湿垃圾的有香蕉皮和苹果核 |
| 分别分类 | 香蕉皮和塑料袋分别属于湿垃圾和干垃圾，仅按顺序一一对应 |
| 纠正句 | 香蕉皮不是干垃圾，而是／但它属于湿垃圾 |
| 无逗号衔接 | 香蕉皮属于湿垃圾并应该丢进垃圾桶里 |
| 连词切换主语 | 香蕉皮应沥干水分而塑料袋应送到回收点，各自绑定对应动作 |

句式示例用于说明抽取能力，不是对每条投放建议的事实核验。动词与前缀可组合，不只针对示例字符串匹配。

## 避免误提取

- 疑问、推测、假设和禁止表达不转成肯定投放关系；否定后明确的纠正陈述可单独提取。
- 描述“表面沾有酸奶”“已经丢进垃圾桶”等背景状态不作为新投放要求。
- 目的地和包裹材料位于已识别的 METHOD 内时，不会抢占主语；多步投放继续关联原物品。
- 主语不明确、分别分类数量不匹配、未限定的多个类别、单数代词指代多个物品时，保守拒绝。
- 保留原文实体位置、原文尾实体与标准名称，规则补全不显示伪造的模型分数。
- 字典字面搜索改用字符串查找，避免每次输入编译数千条正则。

## 使用边界

这是常见句式的系统扩展，不是任意中文理解。输入仍限 128 字，物品依赖现有词典；跨句只支持明确、有限的代词承接，不推断未知物品、复杂指代或隐含关系。条件句和禁止投放的内容仍不会作为肯定三元组输出，尚未新增“禁止投放”关系类型。纯神经模式没有因本次规则扩展自动提高泛化能力，抽取结果仍需人工核验。
