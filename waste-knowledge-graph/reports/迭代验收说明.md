## 与需求的对应关系

| 需求 | 当前实现 |
|---|---|
| 获取和清洗垃圾分类语料 | 保留原Scrapy采集流程，新增CSV/JSONL接入、一致性检查、NFKC规范化、类别映射、来源验证、去重和冲突隔离 |
| BiLSTM-CRF实体识别 | 保留原网络，实现独立新数据目录训练、严格跨度校验与训练字表 |
| BiGRU-Attention关系抽取 | 保留实体位置特征，新增可选关系类别频率加权；无来源方法时不生成虚假投放关系 |
| 训练与实验分析 | 生成弱监督模板训练集，按物品分组；新旧模型同环境复测；评测报告绑定权重指纹 |
| Neo4j知识图谱 | 扩展参数化导入输入及审核状态查询；本地SVG展示与Neo4j Browser明确区分 |
| 查询界面 | 来源筛选、12/24/48条图谱与列表同步分页、分层卡片布局及缩放、证据问答、来源状态与冲突面板、快速查询竞态保护 |

外部分类表的description全部为空，examples全部为字符串形式的空列表，也没有BIO跨度、投放方式、地区或人工复核信息。它不能替代原始网页语料；本次只将其作为来源标签参考和弱监督实验输入。

## 训练与对照结果

随机种子42，按规范物品名分组并按类别分层划分；训练15938句、验证3416句、测试3442句，共22796句。词表仅从训练集拟合。冲突“竹签”排除。各划分共享生成模板，因此即使物品无交叉，也不能声称模板或来源隔离的盲测。

独立新模型训练3轮，最佳为第3轮，训练及评估约105.3秒。结果保存在models_external，未覆盖models。

| 指标 | 原默认模型 | 新实验模型 |
|---|---:|---:|
| 新数据模板测试实体严格F1 | 未运行，不作跨数据集比较 | 99.97% |
| 新数据模板测试关系宏F1 | 未运行，不作跨数据集比较 | 100% |
| 同一5句网页样本端到端三元组F1 | 6.45% | 0% |
| 同一20句改写开发集端到端三元组F1 | 48% | 0% |

关系分类指标使用金标准实体跨度，与端到端三元组指标不是同一口径。网页样本仅5句、18个关系；改写集是开发诊断集，不是完全独立盲测。本轮结果说明新模型拟合了短模板，但没有证明自然文本能力提高，因此不切换默认模型，也不把扩展后的查询目录规模当作神经网络识别能力。

原模型同环境复测保存在reports/baseline_web_current.json和reports/baseline_challenge_current.json。新模型评测分别保存在models_external/web_metrics.json和models_external/challenge_metrics.json。重训后必须重新评测，权重指纹不匹配的额外评测不会显示。

## 自动验收

- Python回归覆盖实体分组无泄漏、BIO校验、CRF损失与梯度、Attention遮罩、数据导入复现、冲突拒绝、分页遍历、图谱上限、模型评测指纹、HTTP参数与跨域请求。
- 前端DOM回归覆盖翻至第8页超过150条、来源筛选重置分页、迟到响应不能覆盖新查询、问答证据与冲突面板、实验页面加载。
- JavaScript语法检查及Python依赖完整性检查通过。
- 原始数据一致性、生成图谱节点与边的引用完整性均通过自动检查。

53项Python测试曾整套通过，最终又按5个测试文件分别复测通过；3项前端DOM测试通过。整套通过记录见reports/tests_iteration.xml，分组复测记录见reports/test_*_iteration.xml，前端结果可用npm test复现。

本机Microsoft Store版Python 3.11在多次复跑时出现间歇性Windows原生访问异常，包括依赖导入阶段；还曾出现与对应比较表达式不相符的运行时异常，单独重跑该测试通过。关闭oneDNN后既有整套通过，也有原生异常再次出现，因此不能声称该设置修复了运行时。tests/conftest.py为数值测试默认设置TF_ENABLE_ONEDNN_OPTS=0，不改变训练和服务配置。当前只能确认上述成功运行结果，不能保证这个本机运行时每次稳定；正式演示前应在干净的Python 3.12环境复验。原生异常根因尚未定位。

## 人工演示步骤

1. 在项目目录运行start.cmd，默认仍加载原模型，并自动读取扩展目录。
2. 搜索阿司匹林，确认显示来源标签、来源链接与未提供投放方法提示。
3. 切换外部来源筛选，翻至第8页，再搜索另一个物品，确认页码回到第一页。
4. 在问答中输入“阿司匹林是什么垃圾”，确认答案是来源标注而非无条件事实。
5. 打开数据与来源，核对3712条、格式一致和竹签冲突。
6. 可选运行start.cmd --model-dir models_external，查看独立实验模型的模板、网页与改写分数，不作为默认替换。

后续优先补充真实网页句子及双人核验的实体跨度和关系标签，按来源页隔离评测；对不确定物态增加人工复核记录，而不是继续仅扩增相同模板。
